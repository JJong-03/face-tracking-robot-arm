# 트러블슈팅 기록

> 프로젝트 후반의 핵심 문제를 `문제 → 원인 → 대응 → 결과` 순서로 정리한 문서다.

## 문제 목록

| 번호 | 문제 | 시기 | 핵심 대응 |
|------|------|------|----------|
| T-01 | Haar-Cascade 검출 신뢰도 한계 | 2학기 4주차 | DNN SSD ResNet-10 전환 |
| T-02 | FHD 전환 시 성능 병목 | 2학기 6주차 | ROI 캐싱, 스레드 분리, Adaptive skip, FP16 |
| T-03 | 정량 지표 미달과 측정 절차 불안정 | 2학기 5~8주차 | 기준 수정, 환경 표준화 |
| T-04 | MG996R의 기계적 진동 한계 | 2학기 5주차 | 고토크 서보 및 짐벌 방향 수립 |
| T-05 | 디지털 서보 교체 후 진동 악화 | 2학기 9주차 | 원인 분석 후 제어 구조 재설계 |
| T-06 | 제어 아키텍처 자체의 불안정 | 2학기 10주차 | PWM 기반 리디자인, 필터·제어기 조합 |

---

## T-01. 얼굴 검출 방식 변경

**문제**: 초기 Haar-Cascade 기반 검출이 조명 변화, 가림, 각도 변화에서 신뢰도가 낮았다.

**원인**: 규칙 기반 검출 방식이라 신뢰도 점수 기반 필터링이 어렵고 환경 변화에 취약했다.

**대응**: DNN 기반 SSD ResNet-10으로 전환. OpenCV DNN Caffe 모델을 사용한다.

**결과**: 검출 안정성이 개선됐다.

---

## T-02. FHD 전환 시 성능 병목

**문제**: VGA(640×480)에서 FHD(1920×1080)로 전환하자 추적과 제어가 정상 동작하지 않을 정도로 지연이 발생했다.

**원인**: DNN 추론과 영상 처리 연산량이 급증하면서 단일 스레드로는 실시간 처리가 불가능했다.

**대응**:
- ROI 사전 계산·캐싱
- 검출/추적 스레드 분리 (`CaptureThread` 기반 비동기 수집)
- Adaptive skip
- OpenCV DNN FP16 최적화

**결과**: FHD 환경에서 `40프레임 이상` 동작이 가능해졌다. 카메라 교체 후에는 `1920×1080, ~50fps` 수준으로 동작했다.

---

## T-03. 정량 지표 미달과 측정 절차 수정

**문제**: 5주차 첫 본측정에서 FRT와 ICR이 목표에 미달. 7주차 추가 측정에서도 판정이 불안정했다.

**원인**:
- FRT: 조도 변화와 피실험자 거리 변화에 영향
- ICR: MG996R의 기계적 진동으로 정지 안정성 미확보
- 측정 환경과 절차가 충분히 표준화되지 않음

**대응**:
- FRT를 단순 시간 측정에서 프레임 비율 기반으로 수정
- IFR10을 IFR20으로 완화
- 우드락 표시목, 줄자, 코드 내부 타이머로 측정 절차 표준화

**결과**: FRT는 수정 기준 적용 후 통과. IFR과 ICR은 이후 하드웨어 보강과 제어 재설계를 거쳐 최종 단계에서 통과했다.

---

## T-04. MG996R의 기계적 진동 한계

**문제**: ICR이 약 `60%`에 그쳐 목표 `80%`를 크게 밑돌았다.

**원인**: 소프트웨어 보정만으로는 MG996R의 기계적 진동과 정지 후 위치 불안정을 충분히 억제할 수 없었다.

**대응**: 디지털 서보와 고토크 모터 교체 방향을 수립. 11주차에 DS3230 Pro 180 적용과 1축 짐벌 추가.

**결과**: 하드웨어 보강이 이후 제어 리디자인과 결합돼 최종 성능 향상으로 이어졌다.

---

## T-05. 디지털 서보 교체 후 진동 악화

**문제**: DS3230 Pro 180으로 교체한 뒤, 기존 PWM 제어값을 그대로 적용하자 오히려 1틱 단위 미세 진동이 심해졌다.

**원인**: 디지털 서보의 응답 속도와 토크 특성이 기존 아날로그 서보 기준 제어 주기와 맞지 않아 오버슈트와 발진이 발생했다.

**대응**: 문제를 하드웨어가 아니라 `서보 특성과 제어 방식의 불일치`로 진단하고, 10주차 제어 시스템 전면 재설계로 이어졌다.

**결과**: 예상 밖 회귀였지만, 제어 아키텍처를 더 근본적으로 개선하는 계기가 됐다.

---

## T-06. 제어 로직 전면 재설계

**문제**: 기존 각도 기반 명령과 낮은 갱신률(`12~25Hz`)로는 디지털 서보 환경에서 안정적인 제어가 어려웠다.

**원인**:
- 각도 기반 미세 입력이 과도한 힘 출력으로 이어짐
- 낮은 갱신률로 빠른 응답을 충분히 활용하지 못함
- 노이즈와 미세 흔들림이 그대로 명령에 반영됨

**대응**:
- PWM 직접 제어 기반으로 전환
- OneEuro 필터 적용
- 비례제어(`Kp_xy=0.02`) + Soft Deadzone + EMA + Adaptive Alpha 도입

**결과**:
- DNN 좌표 노이즈: `±5px → ±1px`
- 제어 갱신률: `12~25Hz → 66~100Hz`
- ICR 방향별: `90.51%`, `94.29%`, `100%`, `100%`
- 최종 발표: FRT·IFR·ICR 3종 충족

---

## 핵심 교훈

- 하드웨어 문제는 소프트웨어 보정만으로 해결되지 않을 수 있다.
- 하드웨어를 바꾸면 기존 제어 파라미터도 함께 다시 설계해야 한다.
- 정량 지표는 측정 기준과 절차까지 포함해 설계해야 의미가 있다.
- 제어 안정화는 "모터를 움직이게 만드는 것"과는 다른 수준의 문제다.
- 기능을 넓게 가져가기보다 핵심 품질에 맞춰 범위를 줄이는 판단이 필요했다.
