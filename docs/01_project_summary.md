# 프로젝트 요약

> 프로젝트의 배경, 진행 흐름, 주요 전환점을 정리한 문서다. 시스템 구조와 기술 스택은 [아키텍처](04_architecture.md), 정량 결과는 [정량 지표](07_quantitative_metrics.md), 역할 분담은 [팀 구성 및 역할](02_team_and_role.md)을 참고한다.

## 프로젝트 한 줄 소개

사용자의 얼굴을 실시간으로 추적해 카메라가 얼굴 중앙을 유지하도록 로봇팔을 자동 제어하는 촬영 보조 시스템

## 해결하려던 문제

1인 촬영 환경에서는 사용자가 움직일 때마다 카메라 구도를 수동으로 다시 맞춰야 한다. 이 프로젝트는 얼굴 위치를 기준으로 카메라 시야를 자동 보정해, 사용자가 이동해도 화면 중심을 유지하는 촬영 보조 시스템을 만드는 것을 목표로 했다.

핵심 기술 과제는 세 가지였다.

- 얼굴 검출 결과를 실시간으로 모터 제어 명령으로 변환하고, Python과 Arduino 사이의 직렬 통신을 안정적으로 연결하는 것
- 서보모터의 기계적 진동과 얼굴 좌표 노이즈가 겹쳐 발생하는 떨림을 제어 로직과 하드웨어 양쪽에서 줄이는 것
- FHD(1920×1080) 해상도에서도 추적이 끊기지 않도록 처리 성능을 확보하는 것

## 진행 흐름

| 시기 | 단계 | 핵심 내용 |
|------|------|-----------|
| 2025.03~04 | 1학기 전반 | 주제 확정, 기능 정의, 초기 부품 선정 (MG996R, C270, Arduino, PCA9685) |
| 2025.04~05 | 1학기 후반 | 음성 명령, 영상 처리, 로봇팔 제어 로직의 초기 구현 착수 |
| 2025.09~10 초 | 2학기 전반 | 정량 지표 3종(FRT·IFR·ICR) 설계, DNN 기반 검출 전환, FHD 최적화 |
| 2025.10 중순~11 | 2학기 후반 | 제어 리디자인, 하드웨어 업그레이드, 최종 시연 및 지표 달성 |

### 1학기: 요구사항 정의와 초기 구현

- 2주차에 `스마트 조명 & 촬영 보조 로봇`이 프로젝트 주제로 확정됐다.
- 5주차에 비전 처리와 모터 제어를 분리한 이중 구조가 정리됐다.
- 후반부에는 음성 명령, 영상 처리, 로봇팔 이동 제어의 초기 구현이 시작됐다.
- 12주차에는 `dx`, `dy`, `dz` 차이값 기반 로봇팔 이동 로직과 `Python → Arduino` 통신 흐름이 만들어졌다.

### 2학기 전반: 정량 지표 설계와 초기 검증

- 음성 명령과 조명 기능은 우선순위에서 제외하고, 카메라-로봇팔 추적 안정화에 집중했다.
- 정량 지표 초안을 수립하고 교수 피드백을 반영해 측정 기준을 강화했다.
- 얼굴 검출을 Haar-Cascade에서 DNN SSD ResNet-10으로 전환했다.
- VGA에서 FHD로 전환하며 ROI 캐싱, 스레드 분리, Adaptive skip, FP16 최적화를 적용했다.
- 5주차 첫 본측정에서 IFR만 통과, FRT와 ICR은 실패했다.

### 2학기 후반: 제어 안정화와 최종 시연

- 디지털 서보 교체 후 미세 진동이 오히려 악화돼, 제어 구조를 전면 재설계했다.
- OneEuro 필터, 비례제어(`Kp_xy=0.02`), Soft Deadzone, EMA, Adaptive Alpha를 적용했다.
- 서보모터를 DS3230 Pro 180으로, 카메라를 StreamCam으로 교체하고 1축 짐벌을 추가했다.
- 최종 발표에서 FRT·IFR·ICR 3종 지표를 충족하고, 정보기술대학장 장려상을 수상했다.

## 주요 전환점

| 시점 | 전환 내용 | 영향 |
|------|----------|------|
| 2학기 시작 | 음성/조명 기능 제외, 추적 안정화 집중 | 프로젝트 범위가 좁아지면서 핵심 품질 향상에 집중 가능 |
| 2학기 4주차 | Haar-Cascade → DNN SSD ResNet-10 | 검출 안정성 확보 |
| 2학기 6주차 | VGA → FHD 전환 + 성능 최적화 | 시스템 구조 전면 재점검 계기 |
| 2학기 9주차 | 디지털 서보 교체 → 진동 악화 발견 | 제어 로직 전면 재설계의 시작점 |
| 2학기 10주차 | 제어 리디자인 (OneEuro, 비례제어, Deadzone, EMA) | 노이즈 ±5px→±1px, 갱신률 12~25Hz→66~100Hz |
| 2학기 11주차 | DS3230 Pro 180 + StreamCam + 짐벌 | 최종 정량 지표 달성 |
