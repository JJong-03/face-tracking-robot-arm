# 팀 구성 및 역할

> 4인 팀의 구성과 역할 분담을 정리한 문서다.

## 팀 개요

| 항목 | 내용 |
|------|------|
| 프로젝트 기간 | 2025년 3월 ~ 11월 (1·2학기) |
| 팀 규모 | 4인 |
| 팀 리더 | 김종원 |
| 수상 | 정보기술대학장 장려상 |

## 팀원별 역할

| 이름 | 역할 |
|------|------|
| 김종원 | 로봇팔 제어 코드 연동, 모터 제어 안정화 및 제어 로직 개선, 속도 최적화, 흔들림 개선, 영상처리 일부 성능 개선, 로봇팔 작동 알고리즘 성능 개선 |
| 김동현 | 로봇팔 속도 최적화, 움직임 중 흔들림 개선 |
| 손홍준 | 로봇팔 하드웨어 설계·제작, 로봇팔 작동 알고리즘 구현 |
| 최민주 | 영상처리 전반, 얼굴 검출, 화면 떨림 보정, 영상처리 알고리즘 구현 |

## 내 역할 상세

### 주도한 영역

- 최종 발표 자료에서 본인 역할이 `로봇팔 제어 코드 연동 구현`, `모터 제어 안정화 및 제어 로직 개선`으로 명시됐다.
- 2학기 10주차에 OneEuro 필터, 비례제어(`Kp_xy=0.02`), Soft Deadzone, EMA, Adaptive Alpha를 적용한 제어 시스템 리디자인을 수행했다.

### 함께 개선한 영역

- 로봇팔 속도 최적화와 움직임 중 흔들림 개선에 참여했다.
- 영상처리 전체를 주도한 것은 아니지만, 일부 성능 개선에 참여했다.
- 로봇팔 작동 알고리즘의 성능 개선 측면에서 기여했다.

## 협업 구조

이 프로젝트는 하드웨어·영상처리·제어 로직이 서로 영향을 주는 구조여서, 각 기능이 완전히 분리되지 않았다. 포트폴리오에서는 `주도한 영역`과 `함께 개선한 영역`을 구분해 설명한다.

## 리더십

- 팀장으로서 태스크 배분, 일정 조율, 발표 자료와 문서화를 함께 맡았다.
- 캡스톤 종료 후 팀원 상호평가에서 높은 점수를 받았다.
- 지도교수는 1학기에는 과제 완성도를 우려했지만, 2학기 들어 눈에 띄게 발전한 점을 긍정적으로 평가했다.
